- Status: Accepted — repository owner approval, 2026-10-18
- Acceptance: Owner approved GMA ADR 028 and this companion decision.
- Date: 2026-10-18
- Governing decision: GMA ADR 028, `docs/adr/028-owner-proven-baselines-for-independent-scene-review.md`
- Scope: Manual interpreter in the approved Studio test campaign
- Protected boundary: existing Scene commit assessment contract, no new writer

Adopt the governing decision's complete problem, authority/time scopes, versioned
logical schemas, prompt/data flow, unchanged budgets, validation/repair behavior,
player failures, compatibility/rollback, observability, examples and acceptance
gates. Runtime implementation remains subordinate to that accepted decision.

GMC owns the canonical closed current-premises schema, source-aware independent
review policy/operation, assessment `/7`, negotiated review binding and strict
owner acceptance. GMA receives generated mirrors, not an independent validator.

The existing Scene writer must independently match supplied premises to its
current owner sources/read set and original pending program. A model claim,
matching digest or adequate verdict alone cannot establish a starting fact.
Current GM-established state and a later attempted maintenance effect retain
different lifetimes. VCS-owned active mechanics stay under VCS authority.

Keep every historical operation, construction profile, issued checkpoint,
assessment and owner receipt readable under its original contract. The new
review replaces, rather than adds to, the existing independent examination.
No larger limit, new provider/model call, VCS modification, global rollout,
failure-counter reset, reply rewrite or completed-action replay is permitted.

Reader/strict-validation delivery precedes new GMA emission and Studio pins.
Fresh independent browser proof and exact Ready deployment precede original
live-scout recovery. Wider human-GM release gates remain held.

## Reader-first implementation evidence

Version 1.14.15 adds the Manual-only source-aware review registration, assessment
7, canonical exact-premise and review-binding validators, and a shared current
owner reader for the HTTP route and protected Scene save. That reader preserves
the existing bounded clock/scheduled-event projection as well as all raw current
Scene views. It cannot query a different scope using incidental commit fields.
Strict acceptance reconstructs and compares complete current source bodies;
matching client hashes alone are insufficient. Historical operations and pending
binding fingerprints are unchanged. No provider call, writer or VCS change is
added. Full check: 1,515 tests, typecheck, lint, contract/provider guards and both
builds pass. GMA activation, final blind browser proof and original live recovery
are separate pending gates, not claimed by this reader-first delivery.
