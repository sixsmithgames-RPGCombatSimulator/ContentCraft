# Manual typed-reference implementation

This is an implementation record, not a separate architecture proposal. The
governing decision is accepted GMA ADR 025,
`docs/adr/025-typed-symbolic-references-and-role-scoped-effect-bindings.md` in
the registered GameMaster Assistant repository. The repository owner explicitly
approved its independent GMC qualification writer. Accepted GMA ADR 024 governs
the lossless preparation working set.

## Ownership and compatibility

GMC independently derives pending-reference qualification from its authenticated
original artifact and retained accepted Manual ticket. It never accepts a
browser's provenance map or chooses a world target. The qualification is an
immutable association; original programs, instructions and completed receipts
are unchanged. The existing examined binding application is the only bridge to
the effective execution view. Scene, movement, mechanics, time and root closure
retain their separate owners and receipts. VCS is unchanged.

Fresh interpretation uses proposal `/3`, compiler `/14`, program `/7` and
freeform binding `/3`. Pending context/binding/record/application use `/5`,
builder and assessment `/6`, preparation policy `/13`, and Manual state `/8`.
All versions must match the complete `typed-pending-reference-binding/1` bundle.
The legacy storage-reader advertisement stays exactly `/2`, `/4`, `/5`, `/6`;
new `/7` support is additive through that bundle, not an incompatible change to
the array used by already deployed clients. All 63 historical operation
definitions and fingerprints remain unchanged. Nine operations are additive.

The original first-pass policy explicitly teaches the `/7`-`/14` provenance
pair, per-effect target roles, the implicit actor selection's exact shape, and
the full advertised examination citation catalog. General, binding and role
reviews retain that catalog through structural adapters. Observer qualification
reviews keep their narrower, independently checked evidence vocabulary.

## Lifetime, recovery and rollout

Accepted ticket evidence remains in its existing collection rather than being
copied into programs. A narrow index migration replaces only the exact old
unconditional expiry index with an unaccepted-state partial expiry index. It
deletes no game record and changes no logical packet deadline. Explicit user
deletion includes the new qualification collection.

After an interrupted plan save, an already accepted action reply is not a
clarification. Discovery verifies the original response, request/output hashes,
shape, semantic policy and workflow membership, and returns the same packet for
its secured reply. It adds no ticket, interpretation or gameplay action.

New emission requires both the existing exact Manual/read-effect campaign gate
and `GMC_TYPED_REFERENCE_BINDINGS=1`. New qualification writes additionally
require `GMC_PENDING_REFERENCE_QUALIFICATION=1` and the exact
`GMC_PENDING_REFERENCE_QUALIFICATION_CAMPAIGN_ALLOWLIST`. Empty lists do not grant
access. Existing-operation discovery remains available during rollback; closed
or foreign workflows never reopen. Keep emission disabled until both canonical
readers and the matching Studio artifact are Ready, then activate only the
approved test campaign. Credentials and provider configuration are unchanged.

## Required acceptance evidence

Run the governing ADR's original/null/owner/role, tamper/scope/CAS, lost-response,
rollback, player-copy and full first-pass-policy tests, plus all repository
checks. Prove fresh blind scout and failed-arrival Manual flows in the Studio
browser with independent examination, immutable original plans, meaningful
visible results, reload recovery, automatic root completion, one-time movement
and time, and zero provider attempts. Stopped or repaired trials are not clean
first-pass proof. Verify exact main commits and Ready deployments before live
recovery. Wider release and human-GM gates remain held until separately met.
