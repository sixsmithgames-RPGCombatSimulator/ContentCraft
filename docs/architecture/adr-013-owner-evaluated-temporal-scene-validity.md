# ADR 013: Owner evaluated temporal Scene validity

- Status: Accepted — repository owner approval, 2026-10-18
- Acceptance: Owner approved GMA ADR 030 and this companion decision, including the protected readiness certificate and consumer changes.
- Date: 2026-10-18
- Governing decision: GMA ADR 030, `docs/adr/030-owner-evaluated-temporal-scene-validity.md`
- Scope: Studio Manual interpreter in the approved test campaign only
- Protected boundary: Readiness certificates, Scene acceptance and every readiness consumer

Adopt the governing decision's complete problem, terminology, authority/state
lifetimes, closed schemas, data/prompt flow, unchanged budgets, validation/repair,
failure boundaries, compatibility, rollback, observability, examples, tests and
acceptance gates. No runtime implementation starts while either decision is
Proposed.

Keep exact preparation clock reads at initial acceptance. A new certificate `/2`
separates those source heads from an independently reviewed temporal validity
manifest. Current clock revisions trigger an owner evaluation of explicit
conditions and complete event evidence, not automatic proof of material change
and not permission to ignore deadlines. Historical certificate `/1` semantics
remain unchanged.

GMC owns the complete bounded temporal authority catalog, canonical evaluator,
source/predicate verification and protected Scene acceptance. The existing Scene
transaction stores the new certificate and pending record `/7`; no new gameplay
writer is introduced. Assessment `/9` retains every prior semantic review. All
coverage, fact-selection, observation and strict settlement consumers must use
the same current-owner evaluator with their existing acceptance/race guards.

Incomplete events, ambiguous time, missing receipt chains, rewinds, source
changes and actual boundary crossings fail closed. An independent judgment is
not a world fact; a manifest cannot schedule or apply consequences. Legacy
natural-language deadlines require explicit owner meaning when no structured
predicate exists. Original replies, completed receipts and consumed model calls
remain immutable.

The existing elapsed-only owner clock remains distinct from a calendar anchor.
A verified nonnegative whole-second initial/monotonic elapsed advance supports
clock-independent records only; it cannot satisfy a calendar deadline, replace
an established calendar clock or silently establish a new anchor mid-chain.
Malformed, partial and decreasing clocks still fail closed.

Deliver readers before GMA emission and exact Studio pins. Preserve all existing
limits, Manual/test-campaign gates and zero-provider behavior. Frozen full-flow
and lost-confirmation proofs, full checks and exact Ready deployments precede
live recovery. No VCS change or wider activation is authorized.

The governing ADR's completeness correction was explicitly approved on
2026-10-18. It replaces the inherited eight-event display count with at most 64 complete
authority records (65-row overflow detection), while keeping the authority byte
bound, all registered model/record/codec limits and every call budget unchanged.
The historical display projection remains unchanged.
